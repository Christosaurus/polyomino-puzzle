## Prompt

```
Create one clean icon sheet for a cozy mobile puzzle game, on a plain flat
background, arranged in a neat 5-by-3 grid with generous spacing.

Style: soft, rounded, friendly, slightly chunky flat icons with a very subtle
inner highlight — like premium mobile game UI icons. Consistent line weight and
size. Warm, saturated but not neon. Each icon simple and instantly readable at
small size. No text, no labels.

The 15 icons, in reading order:
Row 1: a sprouting seedling (Play), a rising sun (Daily), a downward chevron
into a doorway (Descent / going down), a lightning bolt (Cascade / speed),
a five-point star badge (Collection).
Row 2: a glowing light bulb (Hint), an hourglass (Extra time), a small potion
flask (Dissolve / undo), a heart (Life), a faceted crystal shard (Currency).
Row 3: a single filled star (Rating), a closed padlock (Locked), a rounded
checkmark (Done), a pause symbol two bars (Pause), a right-pointing arrow
(Next / continue).

Flat colour, transparent or plain background, high resolution, crisp edges.
```

Danach schneidest du die 15 einzeln aus (oder schickst mir das ganze Sheet, dann
mache ich das). Format je Icon idealerweise 256×256 PNG, transparent.
